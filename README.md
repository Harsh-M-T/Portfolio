## Overview

A 3D portfolio website built with Three.js, featuring custom Blender models, GLSL shaders, and GSAP scroll animations.

**Live Demo:** [My portfolio](https://portfolio-hash-bot.vercel.app/)

---

## Local Development

```bash
# Install dependencies
npm install

# Start development server
npm run dev
```

---

## Tech Stack & Features

| Technology | Purpose |
|------------|---------|
| **Three.js** | 3D rendering & scene management |
| **Blender** | 3D modeling, animation, material design |
| **GLSL Shaders** | Custom procedural textures & patterns |
| **GSAP + ScrollTrigger** | Scroll-based animation timelines |
| **Singleton Pattern** | Modular, single-instance architecture |
| **CSS Keyframes** | Lightweight UI animations |

---

## Project Highlights

- **Blender → Three.js Pipeline**: Models exported as `.glb` with baked textures on UV maps
- **Custom GLSL Shaders**: Procedural patterns animated in real-time on mesh surfaces
- **GSAP ScrollTrigger**: Sequenced animations tied to scroll progress
- **Singleton Architecture**: Centralized state management across modules
